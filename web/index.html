關於這個開發版
  • 只使用虛構的測試資料，只連這台電腦上的 Firebase Emulator，不會部署到網路上。
  • 每次啟動只有一個測試情境；要換情境或回到初始資料，請停止後重新啟動。
  • 受控 API 目前不提供姓名，所以名冊只顯示座號。
  • 點名狀態 P／R／N／U 與假別（例如 SICK-LEAVE）的中文名稱尚未決定，暫時顯示代碼。
  • 日期只能選測試資料中已有的點名場次。
  • 色彩是暫定色票，尚未經負責人核准。
  • 登入使用這台電腦上的 Firebase Auth Emulator 的 Google 登入（虛構帳號），不是真的 Google 帳號。登入只確認身分；能看哪個班級，由後端的授權綁定決定。登入狀態由 Firebase SDK 保存在這個分頁的 sessionStorage，關閉分頁就會登出。
