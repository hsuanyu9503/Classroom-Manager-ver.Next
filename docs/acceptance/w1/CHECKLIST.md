## 0. 啟動、停止與重新啟動

在 `C:\cmn\Classroom-Manager-ver.Next` 執行（`<情境>` 換成下面各節指定的情境）：

```powershell
node dev\launcher.mjs --upstream C:\cmn\cmn-1e20989 --scenario <情境>
```

- 看到 `W1 ready` 後，用瀏覽器打開 http://127.0.0.1:18400/。
- **停止**：回到 PowerShell 按 Ctrl+C。最後一行應該是 `stopped (exit 0); ports confirmed closed; stack cleanup: CLEAN`。
- **一定要停止後重新啟動的時機**：
  1. **換情境**：頁面沒有切換情境或身分的功能；
  2. **想再做一次請假更正**：更正成功後 LV-007 已經是「全天」。重新啟動才會回到初始的「上午 v5」，重新啟動就是重設；
  3. **啟動超過大約 1 小時**：測試身分失效，所有內容都會變成「無法存取」；
  4. **停止時出現 `stop FAILED`、`stopped by FORCE` 或 `REFUSED`**：先截圖回報；如果是 `ports not confirmed closed`，照 `docs/WINDOWS.md`「清除殘留」處理後再啟動。

## 8. 待負責人實際確認（使用感受）

自動測試只能確認「行為正確」，沒辦法判斷「好不好用」。請在第 1～6 節操作時順便留意：

1. **資訊清不清楚**：摘要的 P／R／N／U、「已到」「已登記」、請假摘要的欄位，一看就懂嗎？
2. **按鈕好不好找**：「更正為全天」「確認更正」「重新讀取」「查詢結果」的位置與文字，是否容易找到、不會按錯？
3. **流程是否符合習慣**：「選日期 → 看名冊 → 看請假 → 更正 → 看結果」的順序，符合你平常的使用方式嗎？
