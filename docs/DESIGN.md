# DESIGN｜Classroom Manager ver.Next：視覺與互動規格

> 版本：W1-D0.1（**草案**，待負責人確認 Q-2 與 ChatGPT 審查）　｜　最近更新：2026-11-25
> 依據：負責人提供的既有網站基準 Classroom Manager v2.101（附件 SHA-256 `3ce976a7…`，見 `docs/SPEC.md` §8）。以下 tokens 與慣例是**從 v2.101 的 `style.css` 讀出**的，沿用為 W1 的預設值；負責人確認之前，不視為正式決策。

## 1. 設計目標

- 與既有 Classroom Manager 一致的外觀與操作習慣，讓老師不需要重新學習。
- 情境：課堂中以 iPad 橫向操作為主；也要能在手機與桌面使用。
- 狀態清楚、不誤導：尤其「結果尚未確認」絕不能看起來像「已完成」或「沒有修改」（SPEC §4）。

## 2. 設計 Tokens（取自 v2.101 `style.css` 的 `:root`）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f7fbff` | 頁面背景 |
| `--surface` | `#ffffff` | 卡片、表格 |
| `--text` | `#243047` | 主要文字 |
| `--muted` | `#718096` | 次要文字 |
| `--line` | `#e3ebf6` | 分隔線、邊框 |
| `--primary`／`--primary-soft` | `#6c63ff`／`#f0efff` | 主要按鈕、選取 |
| `--danger`／`--danger-bg` | `#e95d7b`／`#fff0f4` | 錯誤、無法存取 |
| `--warning`／`--warning-bg` | `#e8922f`／`#fff6e7` | **結果尚未確認**、衝突 |
| `--success`／`--success-bg` | `#26a879`／`#eafbf4` | 已完成 |
| `--shadow` | `0 10px 30px rgba(79,96,145,.10)` | 卡片陰影 |
| `--radius` | `18px` | 卡片圓角 |
| 字型 | `system-ui,-apple-system,BlinkMacSystemFont,"Segoe UI","Noto Sans TC",sans-serif` | 全站 |

- 內容寬度：`max-width: 1100px`，左右內距 20px；窄螢幕 12px（沿用 v2.101 的 `.container`）。
- 新增的 token 只在必要時增加，並記錄在本表。

## 3. 排版與響應式

- 三個驗收寬度：
  - **手機** 390 × 844；
  - **平板** 1024 × 768，對應 iPad 橫向的慣例（v2.101 的投影版面以 1408 × 1056 為主，W1 不做投影）；
  - **桌面** 1440 × 900。
- 斷點沿用 v2.101 最常用的三個：`900px`、`620px`、`520px`。
- 任何寬度都**沒有水平捲動**；長名稱與長代碼自動換行。
- P1 名冊：寬螢幕用表格；`620px` 以下改為一欄的卡片清單，每張卡片顯示座號與狀態。

## 4. 主要頁面與狀態

| 頁面 | 重點 |
|---|---|
| 頁首 | 網站名稱；**測試情境標示**（例如「測試情境：S-LEAVE-SC01｜虛構資料」），永遠可見、不能關閉（SPEC §3） |
| P1 名冊與點名摘要 | 摘要列：P／R／N／U、合計、已到、已登記；名冊表格：座號、狀態 |
| P2 請假摘要 | 假別、時段（上午／全天）、版本；不顯示「請假適用」 |
| P3 請假更正 | 確認對話框：說明「上午 → 全天」、目前版本；送出中狀態 |
| P4 結果確認 | 見下表 |

**送出結果的呈現**（SPEC §4）：

| 狀態 | 顏色 | 文字（草案） | 動作 |
|---|---|---|---|
| 已完成 | success | 「已更正為全天（版本 N）。收據：…」 | 關閉 |
| 衝突 | warning | 「資料已被其他裝置更新，請確認最新內容後再決定是否更正。」 | 重新讀取 |
| 結果尚未確認 | warning | 「送出結果尚未確認。修改可能已經完成，也可能沒有完成。」 | 查詢結果、重新送出同一操作 |
| 結果尚未確認，目前無法存取 | warning | 「先前的送出結果尚未確認，目前無法存取。」 | 無（開發情境中需要重新啟動） |
| 無法存取 | danger | 「無法存取。」（沒有權限與資料不存在相同） | 無 |

- 「結果尚未確認」**不得**使用 success 的顏色，也不得使用「已完成」「未修改」之類的字眼。
- 狀態**不只用顏色表示**：一律有文字，加上圖示或標籤。

## 5. 互動與無障礙（沿用 v2.101 的慣例）

- 對話框：Escape 或「返回」可以關閉，關閉後焦點回到原本的按鈕；對話框內 Tab 焦點循環。
- 全程可以只用鍵盤操作；焦點樣式清楚可見。
- 尊重 `prefers-reduced-motion`：減少動畫時，不使用位移或翻轉動畫。
- 送出中的按鈕停用，並有文字標示；送出狀態的變化用 `aria-live="polite"` 宣告。
- 按鈕與互動元件的大小至少 44 × 44 px（觸控）。
